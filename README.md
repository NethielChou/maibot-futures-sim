# 麦麦期货模拟盘

> 让麦麦用自己的判断，在群聊里交易一个**本地虚拟期货账户**。
> 纯娱乐模拟盘：不连接真实券商/期货公司，不构成投资建议。

## 当前状态

- 版本：**0.8.7**
- 自动化测试：**192/192 通过**
- 宿主：MaiBot 1.3.19 / `maibot-plugin-sdk` 2.21.0
- 许可：AGPL-3.0
- 自动交易默认 **关闭**，需要在插件设置页手动开启

## 功能

### 双市场、双账户

| 市场 | 品种 | 账户 |
|---|---|---|
| 国内 | 20 个代表品种 | 1,000,000 麦麦币 |
| 国际 | 9 个代表品种 | 100,000 麦麦币 |

- 国内：原油、黄金、白银、铜、铝、螺纹钢、铁矿石、豆粕、白糖、棉花、甲醇、生猪、玻璃、纯碱、尿素、橡胶、豆油、棕榈油、鸡蛋、苹果
- 国际：布伦特原油、COMEX 金银、LME 铜、CBOT 大豆/玉米/小麦、ICE 棉花/咖啡
- 国内日盘 + 夜盘；国际市场近 24 小时（工作日）
- 国内 3 级自动换月；节假日/节前停夜盘按交易所日历处理

### 行情与模拟交易

- 新浪期货真实行情（国内 `nf_`、国际 `hf_`）
- 模拟撮合：对手价 + 滑点，行情过期/异常不成交
- 本地 SQLite 账本：账户、持仓、成交、决策、结算、权益
- 每日结算：优先交易所官方结算价，缺失回退行情
- 风控：保证金、持仓数、每日笔数、日亏停手、冷却、ATR 止损止盈、到期保护

### 麦麦与群聊

- LLM 只输出交易意图，代码负责权限、风控和最终成交
- 群友只能**影响**麦麦，不能下命令；管理员才能操作
- 可选读取群聊与新闻标题作为决策参考，不落盘
- 支持管理员手动买入/卖出/平仓，与自动交易共用风控
- 所有用户可见回复带模拟盘免责声明
- 插件消息合并成一张转发卡片，减少刷屏

### 官方数据

- 上期所“休市安排”自动同步（含节前停夜盘）
- 上期所/上期能源/郑商所官方结算价自动同步
- 官方源失败时回退静态日历/行情，不阻塞交易

## 命令

查询类所有人可用；控制类仅管理员（插件设置页白名单）。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/期货 状态` | 两个市场的权益、持仓、最近决策 | 所有人 |
| `/期货 状态 cn` / `intl` | 只看一个市场 | 所有人 |
| `/期货 概览` | 国内外行情概览（按大类逐行） | 所有人 |
| `/期货 行情 [品种]` | 行情快照 | 所有人 |
| `/期货 记录 [N]` | 最近成交 | 所有人 |
| `/期货 帮助` | 帮助 | 所有人 |
| `/期货 试跑` | 只让 LLM 决策，不下单 | 管理员 |
| `/期货 暂停` / `恢复` | 暂停/恢复自动交易 | 管理员 |
| `/期货 买 螺纹钢 [手数]` | 手动买入（品种名，后台映射真实合约） | 管理员 |
| `/期货 卖 螺纹钢 [手数]` | 手动卖出 | 管理员 |
| `/期货 平 螺纹钢` | 平仓 | 管理员 |
| `/期货 重置 确认` | 重置全部市场为初始状态 | 管理员 |
| `/期货 重置 cn 确认` | 只重置国内 | 管理员 |
| `/期货 重置 intl 确认` | 只重置国际 | 管理员 |

示例：

```text
/期货 概览
/期货 状态
/期货 买 螺纹钢 1
/期货 重置 cn 确认
```

## 安装

### 从 Release / 市场安装

1. 确认宿主为 MaiBot 1.3.13–1.3.99、SDK 2.21.x
2. 将插件安装到 `plugins/github_nethielchou_mai-futures-sim`
3. 重启或在插件管理页加载
4. 在插件设置页填写：
   - `[notify] group_ids`：允许播报/响应的群号
   - `[admin] users`：管理员（如 `qq:123456`）
   - 需要自动交易时打开 `[decision] auto_trade`
5. 发送 `/期货 状态` 验证

### 从源码

```powershell
git clone https://github.com/NethielChou/maibot-futures-sim
# 将整个目录放到 MaiBot 的 plugins/ 下
```

## 设置页怎么填（新手）

插件设置页已分成 **常用 / 交易 / 高级** 三栏，字段标题和提示都是中文，不需要看英文键名。

1. **常用 → 播报与群聊**：填 `播报群号`，一般填一个测试群。
2. **常用 → 管理员**：填 `qq:你的QQ号`，否则暂停/手动买卖/重置都不能用。
3. **常用 → 市场与品种**：
   - 国内用户只保留 `cn`；想同时跑国际再加 `intl`
   - `品种范围` 一般**留空**，插件会自动使用内置的 20 个国内品种 + 9 个国际品种
   - 确实要限制品种时，可以填中文品种名（如 `螺纹钢`、`甲醇`、`布伦特原油`），不必记合约代码
4. **交易 → 麦麦决策**：`自动交易` 默认关闭。先在群里发 `/期货 状态`、`/期货 试跑` 确认正常，再打开。
5. **高级**：行情、模型参数、官方数据等，不懂就保持默认。

## 配置

配置由宿主按 `config.py` 生成；仓库只提供 `config.example.toml`。

关键项：

- `[market] markets`：`["cn"]`、`["intl"]` 或 `["cn","intl"]`
- `[market] symbols`：高级覆盖，留空使用内置代表品种
- `[account] initial_balance`、`slippage_ticks`、`settle_*`
- `[risk]`：保证金、持仓、每日笔数、日亏停手、ATR
- `[decision] auto_trade`（默认 false）、决策周期、LLM 预算
- `[notify] group_ids`、`merge_messages`（默认 true）、`merge_window_ms`
- `[admin] users`：管理员白名单
- `[influence]`：群聊/新闻影响源（默认关闭）
- `[official]`：交易所官方日历/结算同步（默认开启）
- `[storage]`：本地历史保留条数

> 仓库根目录不包含运行配置 `config.toml`；它由宿主生成并在 `.gitignore` 中排除。

## 数据与隐私

- 账本与官方数据缓存位于插件自己的 `data/plugins/<id>/`，不在仓库
- 插件消息默认不写入宿主消息库（`storage_message=False`）
- 合并转发使用 `processed_plain_text=""`，避免触发 A_Memorix 人物事实写回
- 群聊影响源只读宿主已有聊天记录，不把摘要写入插件存储
- 不提供真实交易通道，不保存任何券商账号/密钥

## 结构

| 文件 | 职责 |
|---|---|
| `plugin.py` | 生命周期、服务装配、Command/Tool 入口 |

| `tools.py` | 只读快照与市场概览 |

| `report.py` / `commands.py` | 播报与命令 |

## 已知限制

- 合约参数（保证金率/手续费）为模拟近似值，不是交易所精确参数
- 国际 `hf_` 行情是连续/主力近似，不按真实月份换月
- 大商所官方结算接口暂不可用，DCE 品种结算回退行情
- CME/ICE 官方结算接口暂不可用，国际结算用最新价近似
- 交易所日历目前同步当前年度；下一年度公告未发布时用静态日历兜底
- 20 个国内品种是代表篮子，不是全市场
- 不模拟涨跌停/停板/交割/期权/订单簿/部分成交
- 所有交易均为本地模拟，不构成投资建议
